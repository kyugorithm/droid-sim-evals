# S02 procedural-box scene snapshot

This policy-free Isaac Lab scene is an image-guided reconstruction of DreamZero
Appendix G(a), task 2: “Put the marker in the blue box.” The paper's image shows
a blue open box, a white-bodied marker with a red cap, and blue-handled scissors
on a wooden tabletop against a gray background. The scissors are included as a
visual distractor.

This is the earlier procedural-box version, retained only for comparison. The
current public-asset candidate is in
[`../s02_public_asset_candidate`](../s02_public_asset_candidate/README.md).

The USD is generated by `scripts/build_appendix_g_scenes.py` from
`configs/appendix_g_tasks.yaml`. The rendered three-camera preview is stored at
[`../../previews/S02_candidate_contact_sheet.png`](../../previews/S02_candidate_contact_sheet.png).
No DreamZero inference or rollout was performed for that preview.

Reference: [DreamZero, Appendix G(a), task 2](https://arxiv.org/html/2602.15922).
