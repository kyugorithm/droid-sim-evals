# S02 public-asset candidate

This policy-free Isaac Lab scene is an image-guided reconstruction of
DreamZero Appendix G(a), seen task 2: “Put the marker in the blue box.” It uses
the CC0 Innerscene Stack Bin model for the blue target, the white/red marker
proxy, the YCB 037 scissors scan as a visual distractor, and a wood tabletop
against a gray background.

The public bin was resized and recolored blue; its front access cutout is not
present in the paper image and is a visible mismatch. The paper does not
publish prop dimensions, exact poses, or camera calibration, so this is not an
official or paper-exact environment. Source and license details are recorded
in [`../../third_party/innerscene/README.md`](../../third_party/innerscene/README.md).

The USD is generated by `scripts/build_appendix_g_scenes.py` from
`configs/appendix_g_tasks.yaml`. Rendered preview:
[`../../previews/S02_public_asset_candidate_contact_sheet.png`](../../previews/S02_public_asset_candidate_contact_sheet.png).
Scene preview performs no DreamZero inference or rollout.

Reference: [DreamZero, Appendix G(a), task 2](https://arxiv.org/html/2602.15922).
